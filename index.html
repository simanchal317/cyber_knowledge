MAP · the shape of a box

CTF / OSCP-style Methodology

The loop every machine follows, whether it's a web app or a bare service. Use this as your checklist when you don't know where else to start.

1 · Recon & Enumeration
▼
Network
  • nmap -sC -sV -p- <target>
  • nmap -sU top ports
  • whatweb / wafw00f
Web
  • gobuster / feroxbuster
  • ffuf vhost fuzzing
  • view-source, robots.txt, JS files
Services
  • enum4linux -a (SMB)
  • showmount -e (NFS)
  • snmpwalk / ldapsearch
▼
2 · Foothold
▼
Web app
  • Exploit vuln class (see Web Vulns)
  • Upload / include a webshell
  • Deserialize / SSTI to RCE
Service
  • Default / weak creds
  • Known CVE for banner version
  • Auth bypass / misconfig
▼
3 · Stabilize shell
▼
python3 -c "import pty;pty.spawn('/bin/bash')"
▼
4 · Local Enumeration
▼
Automated
  • linpeas.sh / winPEAS.exe
  • pspy (Linux, no root)
  • BloodHound (AD)
Manual
  • sudo -l · SUID · capabilities
  • cron jobs · writable paths
  • creds in configs / history
▼

▼
6 · Loot & document (flags, hashes, lessons)
Treat this as a loop, not a line: a foothold on one service often leads back to recon on a newly-visible internal port (pivoting), so steps 1–4 repeat per host.
